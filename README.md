# lxrider.

Independent research in offensive security: attack surface, trust boundaries, identity, IT/OT attack paths and operational consequences.

This repository contains **only the public website source**. Unreviewed manuscripts and sensitive research materials are deliberately kept outside this repository.

## Build

Requires [Zola](https://www.getzola.org/) 0.23.6.

```sh
zola serve
zola build
```

GitHub Actions publishes the output on every push to `main`.
